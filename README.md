# 🖋 Чёрная Игла — сайт тату-студии с записью через Telegram

Одностраничный сайт вымышленной тату-студии: прайс-лист, мастера, онлайн-запись
с живым расчётом стоимости. Заявки с сайта приходят администратору в Telegram.

## Возможности

- **Прайс-лист** — 10 услуг: размеры, сложные зоны, реализм, cover-up, рукав.
- **Мастера** — три мастера с био, стилями, графиком работы и коэффициентом цены.
- **Форма записи**
  - выбор мастера карточками, услуги — из прайса;
  - календарь только с будущими датами, проверка рабочих дней мастера;
  - время — по часам работы выбранного мастера;
  - итоговая цена пересчитывается мгновенно (`цена услуги × коэффициент мастера`);
  - валидация всех полей с понятными подсказками.
- **Telegram-бот** — каждая заявка приходит сообщением:

  ```
  🖋 Новая запись — Чёрная Игла
  Номер: BN-7K2QX

  👤 Анна
  📞 +7 900 123-45-67

  🎨 Мастер: Алиса Ким
  💉 Услуга: Леттеринг / каллиграфия
  📅 Когда: суббота, 31 октября, 15:00
  💰 Стоимость: 5 000 ₽
  ```
- **Защита** — токен бота хранится только на сервере, данные перепроверяются на сервере,
  есть скрытое поле-ловушка от спам-ботов.
- **Адаптивная вёрстка** (mobile-first), тёмная тема, без внешних зависимостей и сборки.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Сайт: HTML + CSS + JS в одном файле. Данные мастеров и цен — в массивах `MASTERS` и `SERVICES` |
| `server.ps1` | Локальный сервер на PowerShell: отдаёт сайт и пересылает заявки в Telegram |
| `start.bat` | Запуск сервера двойным кликом |
| `secrets.example.bat` | Шаблон для токена бота и chat_id |
| `worker.js` | Cloudflare Worker — вариант бэкенда для сайта, размещённого в интернете |

## Запуск локально (Windows)

1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируйте токен.
2. Откройте своего бота в Telegram и нажмите **Start**.
3. Скопируйте `secrets.example.bat` → `secrets.bat` и впишите токен.
4. Запустите `start.bat` — он покажет ваш `chat_id`. Впишите его в `secrets.bat`.
5. Снова запустите `start.bat` и откройте **http://localhost:8080/**.

Ничего устанавливать не нужно — PowerShell встроен в Windows.

## Размещение в интернете

Сайт можно выложить на GitHub Pages, а заявки принимать через Cloudflare Worker (бесплатно):

1. Cloudflare → Workers & Pages → Create Worker → вставьте код из `worker.js`.
2. Добавьте секреты `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` и (по желанию) `ALLOWED_ORIGIN`.
3. В `index.html` укажите адрес воркера в константе `BOOKING_ENDPOINT`.

## Настройка

Все данные редактируются в начале `<script>` в `index.html`:

```js
const SERVICES = [
  { id: 'mini', category: 'Размер', name: 'Мини-тату до 5 см', price: 3000, duration: 1, desc: '…' },
  // …
];

const MASTERS = [
  { id: 'raven', name: 'Марк Ершов', rate: 1, days: [1, 3, 5], hours: { start: 11, end: 20 }, /* … */ },
  // …
];
```

Цвета темы — CSS-переменные в `:root`.
